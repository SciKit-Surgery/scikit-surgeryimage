## Conventions

- Test files mirror source structure: `sksurgeryimage/calibration/foo.py` → `tests/calibration/test_foo.py`
- Test data lives in `tests/data/`, organized by module
- Each source subpackage has an `__init__.py`
- Base/abstract classes use `_internal_*` prefix for methods subclasses override
- The `# coding=utf-8` header is used on all source files
- Docstrings use Sphinx `:param:` / `:return:` / `:raises:` format
- Logging via `logging.getLogger(__name__)` at module level
